Orkest UI is a reusable React component library built with TypeScript. It provides a neutral-first
visual language, semantic design tokens, and accessible primitives that can be shared across React
and Next.js applications.

Complex interactions such as dialogs, menus, popovers, tabs, and selection controls are built on
Base UI (`@base-ui/react`). Orkest UI owns the visual design, public API, and documentation around
it.

The library is intentionally small. Each component is expected to have a clear API, documented
states, tests for user-observable behavior, and a place in the design system.

## Principles

1. **Content leads.** Neutral surfaces and restrained color keep the interface focused.
2. **Tokens first.** Components consume semantic variables instead of raw color values.
3. **Native semantics.** Use the right HTML element before adding ARIA.
4. **Predictable APIs.** Shared concepts use the same prop names and value sets.
5. **Accessibility is part of the definition of done.** Focus, keyboard behavior, and accessible
   names are not optional polish.
