the muted accent and status colors appear only where meaning or interaction requires them.

## Theme behavior

The library provides light and dark mappings. Theme state belongs to the host application:

```html
<html data-orkest-theme="light">
  ...
</html>
```

When the attribute is absent, the stylesheet follows `prefers-color-scheme`. The `color-scheme`
property is set per theme so native controls match.

<Callout type="note" title="Do not communicate state with color alone">
  Pair status colors with text or an icon. The `Text` tone, callout labels, and icon labels in these
  docs follow that rule.
</Callout>

See [Theming](/docs/guides/theming/) for persistence, dark mode, and CSS variable overrides.
