## Reduced motion

The base stylesheet collapses all duration tokens to `0ms` when the user prefers reduced motion:

```css
@media (prefers-reduced-motion: reduce) {
  :root {
    --ok-duration-instant: 0ms;
    --ok-duration-fast: 0ms;
    --ok-duration-normal: 0ms;
    --ok-duration-slow: 0ms;
  }
}
```

Components that animate should use these tokens rather than hard-coded durations.

```css
.button {
  transition:
    background-color var(--ok-duration-fast) var(--ok-ease-standard),
    border-color var(--ok-duration-fast) var(--ok-ease-standard);
}
```
