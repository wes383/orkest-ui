Typography is compact and quietly hierarchical. Inter carries interface text, Plus Jakarta Sans is
an optional display face for large headings, and JetBrains Mono is reserved for code. CJK glyphs
fall back to Noto Sans. Numeric text stays in Inter with tabular figures so digits align in
counters, tables, and timestamps.

<TokenTable title="Font weights" prefix="--ok-font-weight-" />

Regular is the default for body copy. Medium is used for labels and compact emphasis. Semibold is
used for headings and strong emphasis; bold is available for short, high-emphasis runs.
