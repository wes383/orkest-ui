`Table` renders tabular data with the native `table` elements, so rows, columns, and headers reach
assistive technology without extra ARIA. It is presentational only: sorting, filtering, pagination,
and row selection belong to a composed data table, not to this component.

## Row actions

Row actions are ordinary cells: render a `DropdownMenu` with an `IconButton` trigger inside a
`TableCell`. The menu portals out of the table's horizontal scroll container, so it is never clipped
by a cell.

<ComponentPreview
  title="Row actions menu"
  code={`import { Ellipsis, Pencil, Trash2 } from 'lucide-react';
import { IconButton, TableCell } from '@orkest/ui';
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuPortal,
  DropdownMenuTrigger,
} from '@orkest/ui/client';

export function ActionsCell({ invoice }: { invoice: { id: string } }) {
  return (
    <TableCell align="right">
      <DropdownMenu>
        <DropdownMenuTrigger
          render={
            <IconButton
              icon={Ellipsis}
              label={'Actions for ' + invoice.id}
              size="sm"
              variant="ghost"
            />
          }
        />
        <DropdownMenuPortal>
          <DropdownMenuContent align="end">
            <DropdownMenuItem leftIcon={Pencil}>Edit invoice</DropdownMenuItem>
            <DropdownMenuItem leftIcon={Trash2}>Delete</DropdownMenuItem>
          </DropdownMenuContent>
        </DropdownMenuPortal>
      </DropdownMenu>
    </TableCell>
  );
}`}
>
  <TableActionsExample />
</ComponentPreview>

Give each trigger a per-row `label` so the button is not announced as a nameless icon, and keep the
cell right-aligned so the trigger sits against the row edge. [DataTable](/docs/components/data-table/)
shows the same pattern as a column definition.

## Narrow screens

The table scrolls horizontally inside its own container instead of squeezing columns. Keep the
first column readable with `minWidth` when the table has many columns.

## Accessibility

- Every part maps to its native element: `table`, `thead`, `tbody`, `tfoot`, `tr`, `th`, `td`, and
  `caption`. Do not replace them with `div` grids, which would need roles and keyboard handling that
  the platform already provides.
- Give the table an accessible name with `TableCaption` or `aria-label`.
- Header cells default to `scope="col"`. Use `scope="row"` for cells that label their own row.
- Do not use a table for layout. If the content is not tabular, use `Grid` or `Stack`.
- Sorting, filtering, and pagination are not part of this component. When they are needed, compose a
  data table from `Table`, `Checkbox`, `Button`, and `DropdownMenu`, and announce the result count
  outside the table.
