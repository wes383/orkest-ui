---
title: Card
description: Group related content into one surface with optional media and actions.

`Card` groups related content into one visual region: a product, an article, a settings panel, or a
statistic. It owns the surface, the radius, and the inner spacing; the parts own the structure.
Every part is optional, so you can drop arbitrary content straight into the card.

## Variants

export const defaultElevatedAndOutlineCode = `import { Card, CardContent, CardDescription, CardHeader, CardTitle, Stack } from '@orkest/ui';

export function Example() {
  return (
    <Stack direction="row" gap={3} wrap>
      {(['default', 'elevated', 'outline'] as const).map((variant) => (
        <Card key={variant} variant={variant} style={{ width: 200 }}>
          <CardHeader>
            <CardTitle>{variant}</CardTitle>
            <CardDescription>Card variant.</CardDescription>
          </CardHeader>
          <CardContent>Content area.</CardContent>
        </Card>
      ))}
    </Stack>
  );
}`;

      </CardHeader>
      <CardContent>Content area.</CardContent>
    </Card>
    <Card variant="outline" style={{ width: 200 }}>

      </CardHeader>
      <CardContent>Content area.</CardContent>
    </Card>
  </Stack>

`default` sits on the page surface with a border. `elevated` raises the card with a shadow and adds
no border. `outline` keeps the border but removes the background, which suits cards placed on an
already tinted surface. Shadow is the only elevation control — hover and pressed states belong to
whatever element performs the action, not to the surface.

`padding` is a single shared value: the parts do not add their own, so the card keeps one rhythm.
Use `padding="none"` when the content needs to control its own spacing, for example a table or a
full-bleed list.

## Media

export const fullBleedMediaCode = `import { Card, CardContent, CardDescription, CardHeader, CardMedia, CardTitle } from '@orkest/ui';

export function Example() {

`CardMedia` cancels the card padding on the sides it touches, so images reach the edges and are
clipped by the card radius. Give images an empty `alt` when they are decorative, and a descriptive
one when they carry meaning.

## Cards that link

Render the card as an anchor instead of wrapping it in one. The card then keeps native focus,
keyboard activation, and context-menu behavior:

export const linkedCardCode = `import { Card, CardDescription, CardHeader, CardTitle, Icon, Stack } from '@orkest/ui';
import { ArrowUpRight } from 'lucide-react';

export function Example() {
  return (
    <Card as="a" href="/docs/components/button/" style={{ width: 260 }}>
      <Stack direction="row" justify="between" align="start" gap={3}>
        <CardHeader>
          <CardTitle>Buttons</CardTitle>
          <CardDescription>Sizes, variants, icons, and loading states.</CardDescription>
        </CardHeader>
        <Icon icon={ArrowUpRight} size="sm" tone="muted" />
      </Stack>
    </Card>
  );
}`;

<ComponentPreview
  title="Linked card"
  code={linkedCardCode}
>
  <Card as="a" href="/docs/components/button/" style={{ width: 260 }}>
    <Stack direction="row" justify="between" align="start" gap={3}>
      <CardHeader>
        <CardTitle>Buttons</CardTitle>
        <CardDescription>Sizes, variants, icons, and loading states.</CardDescription>
      </CardHeader>
      <Icon icon={ArrowUpRight} size="sm" tone="muted" />
    </Stack>
  </Card>

Do not nest links or buttons inside a card that is itself a link — the nested target becomes
unreachable for pointer and screen-reader users. When a card needs several actions, keep the card a
`div` and place the actions in `CardFooter`.

## Accessibility

- `Card` renders a `div` and carries no role. It is a visual grouping, not a landmark; add
  `aria-labelledby` pointing at the title only when the grouping needs an accessible name.
- `CardTitle` renders an `h3` by default. Pass `level` to match the surrounding document outline
  instead of skipping heading levels.
- Render a clickable card as `a` or `button` through `as`, so focus, Enter, and Space work without
  extra handlers. Avoid `onClick` on the default `div` root.
- Focus is visible on the card itself (`:focus-visible`), so a linked card needs no extra styling.
