`Separator` draws a horizontal or vertical divider. It is decorative by default. Set
`decorative={false}` when the break conveys document structure rather than visual rhythm.

## Semantic separators

Decorative separators are hidden from assistive technology. When the divider marks a meaningful break,
opt into separator semantics:

```tsx
<Separator decorative={false} />
<Separator orientation="vertical" decorative={false} />
```

Both render `role="separator"` and set `aria-orientation` from `orientation`. Use this only when the
break is part of the content structure; purely visual lines should stay decorative.

## Accessibility

- `decorative` defaults to `true`, which renders `aria-hidden="true"` and no role. Screen readers
  ignore the line.
- With `decorative={false}`, the separator renders `role="separator"` and sets `aria-orientation` to
  `horizontal` or `vertical`.
- Do not simulate a meaningful divider with a plain CSS border on a decorative element. Use
  `decorative={false}` so the break is exposed in the accessibility tree.
- The separator is not interactive and never receives keyboard focus.
- Vertical separators stretch in flex layouts and keep a minimum height when the parent does not
  stretch its children.
