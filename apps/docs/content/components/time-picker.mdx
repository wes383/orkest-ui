`TimePicker` selects a time of day, not a moment. The value is `HH:mm` (or `HH:mm:ss` with
`showSeconds`), always written in 24-hour form, so `13:45` is stored as `13:45` even when the field
reads `1:45 PM`.

A time has no date and no timezone, so the value stays a string: no conversion, no accidental
offset, and a value that can be sent to an API unchanged.

## Live preview

export const basicTimePickerCode = `import { useState } from 'react';
import { Stack, Text } from '@orkest/ui';
import { TimePicker } from '@orkest/ui/client';

export function Example() {
  const [value, setValue] = useState<string | null>('09:30');

return (

<Stack gap={2} align="start" style={{ width: '100%', maxWidth: '12rem' }}>
<TimePicker value={value} onChange={setValue} />
<Text size="sm" tone="muted">
Value: {value ?? 'none'}
</Text>
</Stack>
);
}`;

Each unit is its own segment: `hh`, `mm`, and `ss` when seconds are shown, plus `AM/PM` in 12-hour
mode. Clicking a segment selects its digits, so typing replaces the whole unit instead of inserting
next to them. The value advances to the next segment as soon as the digits are unambiguous, so `1430`
fills hours and minutes without a separator. `ArrowUp` and `ArrowDown` step the focused segment, the
horizontal arrows move between segments, and `Backspace` clears the segment under the focus.

The field only commits once every segment is filled. Clearing one unit leaves the field showing the
remaining segments until the time is complete again.

## 12-hour display

`format` only changes the display. The stored value stays 24-hour, so a switch to `12h` never rewrites
what your data layer already holds.

The hour segment shows a zero-padded 12-hour clock face (`01`-`12`) and the day-period segment
beside it holds `AM` or `PM`; typing `a` or `p` while it is focused flips the period. The panel keeps
a single hour column of all 24 hours with the period folded into the label, so `1 PM` stays one
click there.

## Minute step, seconds, and range

`minuteStep` trims the minute column to the intervals you actually accept and sets the arrow-key
step for the minute segment. `showSeconds` adds a seconds segment and column and widens the stored
value to `HH:mm:ss`. `minTime` and `maxTime` bound the columns, typed entry, and segment stepping.

export const secondsAndAWorkingHoursRangeCode = `import { useState } from 'react';
import { TimePicker } from '@orkest/ui/client';

export function Example() {
  const [value, setValue] = useState<string | null>('09:30:00');

return (

<TimePicker
value={value}
onChange={setValue}
showSeconds
minTime="08:00"
maxTime="18:00"
style={{ width: '100%', maxWidth: '12rem' }}
/>
);
}`;

## Hiding the actions

`showIcon={false}` removes the clock action that opens the panel. Every segment still accepts typed
digits and arrow-key stepping. `clearable={false}` removes the clear action.

## Composition

`TimePicker` is built from parts you can use on their own:

- The field is segmented: one `role="spinbutton"` per unit, each with its own label and value range.
- `TimePickerContent` is the panel body that lays columns out side by side.
- `TimePickerColumn` is one scrollable list (`role="listbox"`) with roving `tabindex`.
- `TimePickerItem` styling ships with the column; reach for `TimePickerColumn` when you need a
  different option set.

```tsx
import { TimePickerColumn } from '@orkest/ui/client';

export function HalfHours({ value, onChange }: { value: number; onChange: (v: number) => void }) {
  return (
    <TimePickerColumn
      label="Minutes"
      value={value}
      options={[0, 30].map((minute) => ({
        value: minute,
        label: String(minute).padStart(2, '0'),
      }))}
      onValueChange={onChange}
    />
  );
}
```

## Accessibility

- The field is a `group` of `spinbutton`s. Each segment carries its own label, `aria-valuenow`,
  `aria-valuemin`, and `aria-valuemax`, so screen readers announce the unit and its value.
- Segments are separate tab stops. The horizontal arrows and `Home`/`End` also move between them, so
  the whole time can be edited without leaving the keyboard.
- The selected digits are the focus indicator, as in a native time field: the field does not draw a
  ring around the unit, and the highlight stays on the unit that owns the focus.
- The clock button at the start of the field is a separate, labelled button with
  `aria-haspopup="dialog"`.
- Inside the panel each column is a labelled listbox. `ArrowUp` and `ArrowDown` move the selection,
  `Home` and `End` jump to the ends, and `ArrowLeft` and `ArrowRight` move between columns.
- Selected options carry `aria-selected`, and unavailable ones carry `aria-disabled` rather than being
  removed, so the list does not reflow under the pointer.
