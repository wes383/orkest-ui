`IconButton` is a square, icon-only variant of [Button](/docs/components/button/). The `label` prop is
required and becomes the button's accessible name, so the icon never carries meaning on its own.

Use it for compact actions such as add, edit, settings, or delete. For buttons with visible text, use
`Button`.

## Accessibility

- `label` is required and becomes the accessible name. Never rely on the icon alone.
- The icon is decorative and hidden from assistive technology.
- The component renders a native `<button>` with `type="button"` by default.
- Loading sets the native disabled state and `aria-busy="true"`, matching `Button`.
- Focus-visible and disabled styles use the same tokens and behavior as `Button`.
- For navigation, use a link element with an accessible name instead of `IconButton`.
