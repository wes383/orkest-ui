`Checkbox` is a native checkbox input with token styling and an optional label. It supports controlled
and uncontrolled usage, native form submission, and an indeterminate visual state.

Import it from `@orkest/ui/client` because the indeterminate state is synchronized on the client.

## Indeterminate

`indeterminate` is an independent visual and ARIA state. It does not change the checkbox's checked
value; update `checked` yourself after a selection changes.

<ComponentPreview
  title="Select all"
  code={`import { useState } from 'react';
import { Stack } from '@orkest/ui';
import { Checkbox } from '@orkest/ui/client';

const teams = ['Design', 'Engineering', 'Product'];

export function Example() {
  const [selected, setSelected] = useState(['Design']);
  const allSelected = selected.length === teams.length;
  const partiallySelected = selected.length > 0 && !allSelected;

  return (
    <Stack gap={2}>
      <Checkbox
        label="All teams"
        checked={allSelected}
        indeterminate={partiallySelected}
        onChange={() => setSelected(allSelected ? [] : teams)}
      />
      {teams.map((team) => (
        <Checkbox
          key={team}
          label={team}
          checked={selected.includes(team)}
          onChange={() =>
            setSelected((current) =>
              current.includes(team)
                ? current.filter((item) => item !== team)
                : [...current, team],
            )
          }
        />
      ))}
    </Stack>
  );
}`}
>
  <IndeterminateCheckboxExample />
</ComponentPreview>

## Accessibility

- Renders a native `<input type="checkbox">`, so Space toggles it and `required` participates in
  native form validation.
- The optional `label` is an implicit label. When omitting it, provide `aria-label` or connect an
  external label with `id` and `htmlFor`.
- `indeterminate` sets both the DOM indeterminate property and `aria-checked="mixed"`.
- Focus is shown on the custom control with `:focus-visible`.
- Disabled controls are removed from form submission and cannot be toggled.
