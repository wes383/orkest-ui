`Checkbox` is a Base UI checkbox with token styling and an optional label. It supports controlled and
uncontrolled usage, native form submission, and an indeterminate state.

Import it from `@orkest/ui/client`.

## Live preview

## Indeterminate

`indeterminate` is an independent visual and ARIA state managed by Base UI. It does not change the
checkbox's checked value; update `checked` yourself after a selection changes.

export const selectAllCode = `import { useState } from 'react';
import { Stack } from '@orkest/ui';
import { Checkbox } from '@orkest/ui/client';

const teams = ['Design', 'Engineering', 'Product'];

export function Example() {
  const [selected, setSelected] = useState(['Design']);
  const allSelected = selected.length === teams.length;
  const partiallySelected = selected.length > 0 && !allSelected;

return (

<Stack gap={2}>
<Checkbox
label="All teams"
checked={allSelected}
indeterminate={partiallySelected}
onCheckedChange={() => setSelected(allSelected ? [] : teams)}
/>
{teams.map((team) => (
<Checkbox
key={team}
label={team}
checked={selected.includes(team)}
onCheckedChange={() =>
setSelected((current) =>
current.includes(team)
? current.filter((item) => item !== team)
: [...current, team],
)
}
/>
))}
</Stack>
);
}`;

<ComponentPreview title="Select all" code={selectAllCode}>
  <IndeterminateCheckboxExample />
</ComponentPreview>

## Accessibility

- Renders a Base UI checkbox with `role="checkbox"` and a hidden native input, so Space toggles it
  and `required` participates in form validation.
- The optional `label` is an implicit label. When omitting it, provide `aria-label`, use
  `FieldLabel`, or connect an external label through the Base UI field context.
- `indeterminate` sets `aria-checked="mixed"` and the hidden input's indeterminate state.
- Focus is shown on the custom control with `:focus-visible`.
- Disabled controls are removed from form submission and cannot be toggled.
