`Tag` is a chip for removable or clickable labels. It shares variants, sizes, shapes, icons, and
custom colors with [Badge](/docs/components/badge/), but owns the interactive and remove behavior.
Badge remains the choice for read-only status, status dots, and counts.

Use `Badge` when the label is informational. Use `Tag` when the label can be removed or selected.

## Removable

Removable tags stay non-interactive as a whole so the remove action can be a native button.

export const removableTagsCode = `import { useState } from 'react';
import { Stack, Tag } from '@orkest/ui';

export function Example() {
  const [tags, setTags] = useState(['Design', 'Engineering']);

  return (
    <Stack direction="row" gap={2} wrap>
      {tags.map((tag) => (
        <Tag
          key={tag}
          removable
          onRemove={() => setTags((current) => current.filter((item) => item !== tag))}
        >
          {tag}
        </Tag>
      ))}
    </Stack>
  );
}`;

</ComponentPreview>

      interactive
      variant={active ? 'success' : 'outline'}

## Accessibility

- Static tags render a `span`; interactive tags render a native `<button type="button">`.
- Removable tags keep the root non-interactive so the remove action can be a native button.
  `interactive` is ignored when `removable` is set.
- The remove action has an accessible name from `removeLabel`.
- Interactive tags support keyboard activation and a focus-visible ring.
- Icons are decorative and hidden from assistive technology.
- Do not communicate status with color alone. Pair variants, dots, and custom colors with text.
- Check contrast when using custom colors.
