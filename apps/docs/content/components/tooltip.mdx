`Tooltip` explains an element with a short piece of text. Use it for icon buttons, shortcut hints,
and brief clarification. Do not put buttons, links, forms, or other interactive content inside a
tooltip; use [Popover](/docs/components/popover/) instead.

The component is built on Base UI Tooltip. Import it from `@orkest/ui/client`.

## Basic usage

Wrap tooltips in `TooltipProvider` to share the hover delay. The provider defaults to a `500ms` open
delay and no close delay.

export const iconButtonTooltipsCode = `import { IconButton, Kbd, Stack } from '@orkest/ui';
import {
  Tooltip,
  TooltipArrow,
  TooltipContent,
  TooltipPortal,
  TooltipProvider,
  TooltipTrigger,
} from '@orkest/ui/client';
import { Copy, Settings, SlidersHorizontal } from 'lucide-react';

export function Example() {
  return (
    <TooltipProvider delay={300}>
      <Stack direction="row" gap={3} align="center">
        <Tooltip>
          <TooltipTrigger
            render={<IconButton icon={Settings} label="Settings" variant="outline" />}
          />
          <TooltipPortal>
            <TooltipContent>
              Manage workspace settings
              <TooltipArrow />
            </TooltipContent>
          </TooltipPortal>
        </Tooltip>
        <Tooltip>
          <TooltipTrigger
            render={<IconButton icon={SlidersHorizontal} label="Filters" variant="outline" />}
          />
          <TooltipPortal>
            <TooltipContent>Filter the current results</TooltipContent>
          </TooltipPortal>
        </Tooltip>
        <Tooltip>
          <TooltipTrigger render={<IconButton icon={Copy} label="Copy link" variant="outline" />} />
          <TooltipPortal>
            <TooltipContent>
              Copy link <Kbd size="sm">⌘C</Kbd>
            </TooltipContent>
          </TooltipPortal>
        </Tooltip>
      </Stack>
    </TooltipProvider>
  );
}`;

## Anatomy

- `TooltipProvider` configures the shared delay and close delay.
- `Tooltip` owns the open state.
- `TooltipTrigger` shows the tooltip on hover and keyboard focus.
- `TooltipPortal` moves the tooltip to the document body.
- `TooltipContent` renders the short hint.
- `TooltipArrow` adds an optional arrow.

## Text triggers and shortcuts

`TooltipContent` accepts short text and inline shortcut hints. Avoid block-level interactive
components.

export const textTriggerCode = `import {
  Tooltip,
  TooltipContent,
  TooltipPortal,
  TooltipProvider,
  TooltipTrigger,
} from '@orkest/ui/client';

export function Example() {
  return (
    <TooltipProvider delay={200}>
      <Tooltip>
        <TooltipTrigger variant="link">What is a workspace?</TooltipTrigger>
        <TooltipPortal>
          <TooltipContent maxWidth="14rem">
            A workspace groups projects, members, and billing in one place.
          </TooltipContent>
        </TooltipPortal>
      </Tooltip>
    </TooltipProvider>
  );
}`;

## Positioning and arrow

`TooltipContent` defaults to `side="top"`, `align="center"`, and `sideOffset={6}`. It flips
automatically when the tooltip would overflow the viewport.

export const rightAlignedTooltipCode = `import {
  Tooltip,
  TooltipArrow,
  TooltipContent,
  TooltipPortal,
  TooltipProvider,
  TooltipTrigger,
} from '@orkest/ui/client';

export function Example() {
  return (
    <TooltipProvider delay={0}>
      <Tooltip>
        <TooltipTrigger variant="outline">Hover for details</TooltipTrigger>
        <TooltipPortal>
          <TooltipContent side="right" align="start" sideOffset={10}>
            <TooltipArrow />
            Prefers the right side and aligns to the start of the trigger.
          </TooltipContent>
        </TooltipPortal>
      </Tooltip>
    </TooltipProvider>
  );
}`;

## Accessibility

- `TooltipContent` uses `role="tooltip"`.
- `TooltipTrigger` receives `aria-describedby` pointing to the tooltip.
- A tooltip is supplemental. Keep the trigger's own accessible name with `aria-label` or visible
  text; do not use the tooltip as the only label.
- Tooltips appear for pointer hover and keyboard focus. Do not hide essential information behind a
  tooltip, because touch users may not discover it.
- For an information icon that reveals interactive content, prefer a [Popover](/docs/components/popover/)
  with `openOnHover` so touch users can also click it.
- Escape closes the tooltip.
- The tooltip respects `prefers-reduced-motion` for its open and close animation.
