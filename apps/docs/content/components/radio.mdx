`Radio` is a radio control. `RadioGroup` manages a set of radios with a shared name, controlled or
uncontrolled value, orientation, disabled, required, and read-only states, plus arrow-key navigation
and form integration.

Render `Radio` inside a `RadioGroup`. Import both from `@orkest/ui/client`.

## Live preview

export const radioGroupCode = `import { useState } from 'react';
import { Radio, RadioGroup } from '@orkest/ui/client';

export function Example() {
  const [value, setValue] = useState('standard');

  return (
    <RadioGroup aria-label="Plan" value={value} onValueChange={setValue} orientation="horizontal">
      <Radio value="standard" label="Standard" />
      <Radio value="pro" label="Pro" />
      <Radio value="enterprise" label="Enterprise" />
    </RadioGroup>
  );
}`;

## Vertical and horizontal

`orientation` controls layout only. The default is vertical; horizontal groups wrap when needed.

export const verticalGroupCode = `import { Radio, RadioGroup } from '@orkest/ui/client';

export function Example() {
  return (
    <RadioGroup aria-label="Notifications" defaultValue="all">
      <Radio value="all" label="All activity" />
      <Radio value="mentions" label="Mentions only" />
      <Radio value="none" label="Nothing" />

}`;

## Sizes and disabled

`RadioGroup` passes `size` to its radios. A radio can override the group size with its own `size`.

export const sizesAndDisabledGroupCode = `import { Stack } from '@orkest/ui';
import { Radio, RadioGroup } from '@orkest/ui/client';

export function Example() {
  return (
    <Stack gap={4}>
      <RadioGroup aria-label="Small plan" size="sm" defaultValue="basic">
        <Radio value="basic" label="Basic" />
        <Radio value="pro" label="Pro" />
      </RadioGroup>
      <RadioGroup aria-label="Disabled plan" defaultValue="basic" disabled>
        <Radio value="basic" label="Disabled option" />
        <Radio value="pro" label="Another option" />
      </RadioGroup>
    </Stack>
  );
}`;

<ComponentPreview title="Sizes and disabled group" code={sizesAndDisabledGroupCode}>

      <Radio value="basic" label="Basic" />
      <Radio value="pro" label="Pro" />
    </RadioGroup>
    <RadioGroup aria-label="Disabled plan" defaultValue="basic" disabled>

## Accessibility

- `RadioGroup` exposes `role="radiogroup"`; each radio exposes `role="radio"` and submits with native
  forms.
- Give `RadioGroup` an accessible name with `aria-label`, `aria-labelledby`, or `FieldLabel`.
- Arrow keys move between radios and select as they move.
- A radio cannot be unchecked by clicking it again. The user must select another option.
- `disabled`, `required`, and `readOnly` are exposed on the group and applied to each radio.
- Keyboard focus is visible on the control.
