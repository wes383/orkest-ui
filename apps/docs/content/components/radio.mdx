`Radio` is a native radio input. `RadioGroup` manages a set of radios with a shared name, controlled
or uncontrolled value, orientation, disabled and required states, and native arrow-key navigation.

Import both from `@orkest/ui/client`.

## Live preview

  title="Radio group"
  code={`import { useState } from 'react';
import { Radio, RadioGroup } from '@orkest/ui/client';

export function Example() {
  const [value, setValue] = useState('standard');

  return (
    <RadioGroup
      aria-label="Plan"

## Vertical and horizontal

`orientation` controls layout only. The default is vertical; horizontal groups wrap when needed.

<ComponentPreview
  title="Vertical group"
  code={`import { Radio, RadioGroup } from '@orkest/ui/client';

## Sizes and disabled

`RadioGroup` passes `size` to its radios. A radio can override the group size with its own `size`.

<ComponentPreview
  title="Sizes and disabled group"
  code={`import { Stack } from '@orkest/ui';
import { Radio, RadioGroup } from '@orkest/ui/client';

export function Example() {
  return (
    <Stack gap={4}>
      <RadioGroup aria-label="Small plan" size="sm" defaultValue="basic">
        <Radio value="basic" label="Basic" />
        <Radio value="pro" label="Pro" />
      </RadioGroup>
      <RadioGroup aria-label="Disabled plan" defaultValue="basic" disabled>
        <Radio value="basic" label="Disabled option" />
        <Radio value="pro" label="Another option" />
      </RadioGroup>
    </Stack>
  );
}`}
>
  <Stack gap={4}>
    <RadioGroup aria-label="Small plan" size="sm" defaultValue="basic">
      <Radio value="basic" label="Basic" />
      <Radio value="pro" label="Pro" />
    </RadioGroup>
    <RadioGroup aria-label="Large plan" size="lg" defaultValue="basic">
      <Radio value="basic" label="Basic" />
      <Radio value="pro" label="Pro" />
    </RadioGroup>
    <RadioGroup aria-label="Disabled plan" defaultValue="basic" disabled>
      <Radio value="basic" label="Disabled option" />
      <Radio value="pro" label="Another option" />
    </RadioGroup>
  </Stack>
</ComponentPreview>

## Accessibility

- Radios render native `<input type="radio">` elements with the same generated `name`, so browser
  arrow-key navigation and form semantics work without custom keyboard handlers.
- Give `RadioGroup` an accessible name with `aria-label` or `aria-labelledby`; it renders
  `role="radiogroup"` and `aria-orientation`.
- A radio cannot be unchecked by clicking it again. The user must select another option.
- `disabled` and `required` are exposed on the group and applied to each radio.
- Focus is shown on the custom control with `:focus-visible`.
