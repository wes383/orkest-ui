`MultiSelect` extends the Select interaction model to multiple values. Selected options render as
removable tags, the listbox exposes `aria-multiselectable`, and the menu stays open while toggling
options.

Import it from `@orkest/ui/client`.

## Live preview

import { MultiSelect } from '@orkest/ui/client';

export function Example() {
  const [selected, setSelected] = useState(['design', 'frontend']);

  return (
    <MultiSelect
      aria-label="Teams"
      options={options}
      value={selected}
      onChange={(nextValues) => setSelected(nextValues)}

      hideSelected
      clearable
      maxSelected={3}

## Selection, search, and tags

Each selected value renders as a removable tag. Removing a tag updates the value array immediately.
`clearable` adds a clear action that removes every selection. With `searchable`, typing filters the
menu; `hideSelected` removes already selected options from the menu so only remaining choices are
shown.

```tsx
<MultiSelect
  aria-label="Teams"
  options={options}
  defaultValue={['design']}
  searchable
  hideSelected
  clearable
/>
```

## Selection limits

`maxSelected` disables unselected options once the limit is reached. Selected options stay
interactive so the user can replace a choice.

```tsx
<MultiSelect aria-label="Teams" options={options} maxSelected={3} />
```

## Custom value content

Override the default tags with `renderValue`. The callback receives selected options and a `remove`
function:

```tsx
<MultiSelect
  aria-label="Teams"
  options={options}
  defaultValue={['design', 'frontend']}
  renderValue={(selected, remove) => (
    <span>
      {selected.length} selected
      <button type="button" onClick={() => remove('design')}>
        Remove Design
      </button>
    </span>
  )}
/>
```

## Accessibility

- The combobox input renders `role="combobox"` with `aria-expanded`, `aria-controls`, and
  `aria-activedescendant`. The popup renders `role="listbox"` with `aria-multiselectable="true"`.
- Selected options expose `aria-selected="true"`; `Space` and `Enter` toggle the active option without
  closing the menu. `Escape` closes and restores focus.
- When `searchable` is false, letter keys perform typeahead. When it is true, typing filters instead.
- Default tags include a labelled remove action. `renderValue` replaces this content; the wrapper
  stops click propagation so custom controls do not toggle the menu.
- `required` sets `aria-required`. The `name` prop renders one hidden input per selected value. Native
  constraint validation is not triggered by this custom control; validate in the form submit handler.
- A visually hidden live region announces the number of selected values.
