`MultiSelect` extends the Select interaction model to multiple values. Selected options render as
removable chips, and the listbox exposes `aria-multiselectable`.

It shares the combobox core with [Combobox](/docs/components/combobox/), so filtering, groups,
custom rows, and the loading and empty rows behave the same way in both.

Import it from `@orkest/ui/client`.

## Live preview

export const searchableMultiSelectCode = `import { useState } from 'react';
import { MultiSelect } from '@orkest/ui/client';

const skills = [
  { value: 'react', label: 'React' },
  { value: 'typescript', label: 'TypeScript' },
  { value: 'node', label: 'Node.js' },
  { value: 'css', label: 'CSS' },
  { value: 'testing', label: 'Testing' },
  { value: 'accessibility', label: 'Accessibility' },
];

export function Example() {
  const [selected, setSelected] = useState(['react', 'typescript']);

  return (
    <MultiSelect
      aria-label="Skills"
      options={skills}
      value={selected}
      onChange={(nextValues) => setSelected(nextValues)}
      searchable
      hideSelected
      clearable
      maxSelected={3}
      placeholder="Select skills"
    />
  );
}`;

<ComponentPreview title="Searchable multi-select" code={searchableMultiSelectCode}>
  <MultiSelectExample />
</ComponentPreview>

## Selection, search, and tags

Each selected value renders as a removable tag. Removing a tag updates the value array immediately.
`clearable` adds a clear action that removes every selection. With `searchable`, typing filters the
menu; `hideSelected` removes already selected options from the menu so only remaining choices are
shown.

```tsx
<MultiSelect
  aria-label="Skills"
  options={skills}
  defaultValue={['react']}
  searchable
  hideSelected
  clearable
/>
```

## Selection limits

`maxSelected` disables unselected options once the limit is reached. Selected options stay
interactive so the user can replace a choice. The field shows the current count as `selected/max`
at the right edge.

```tsx
<MultiSelect aria-label="Skills" options={skills} maxSelected={3} />
```

## Select all

`selectAll` pins an action above the options. It selects every enabled option that is currently in
the list, so it composes with `searchable`: with a query active, only the matches are added. When
everything selectable is already on, the same row switches to `clearAllLabel` and removes them.

export const selectAllCode = `import { MultiSelect } from '@orkest/ui/client';

export function Example() {
  return (
    <MultiSelect
      aria-label="Skills"
      options={skills}
      selectAll
      searchable
      clearable
      placeholder="Select skills"
    />
  );
}`;

<ComponentPreview title="Select all" code={selectAllCode}>
  <MultiSelectSelectAllExample />
</ComponentPreview>

Disabled options are never selected by the row. If `maxSelected` is also set, the row stops at the
limit instead of overshooting it.

## Chip overflow

`maxVisible` keeps the field to one line: the chips past the limit collapse into a counter chip that
expands the rest when clicked.

export const chipOverflowCode = `import { MultiSelect } from '@orkest/ui/client';

export function Example() {
  return (
    <MultiSelect
      aria-label="Skills"
      options={skills}
      defaultValue={['react', 'typescript', 'node', 'css', 'testing']}
      maxVisible={2}
      clearable
    />
  );
}`;

<ComponentPreview title="Chip overflow" code={chipOverflowCode}>
  <MultiSelectOverflowExample />
</ComponentPreview>

The counter is a button with an accessible name, so keyboard users can reveal the hidden chips too.

## Custom value content

Override the default tags with `renderValue`. The callback receives selected options and a `remove`
function:

```tsx
<MultiSelect
  aria-label="Skills"
  options={skills}
  defaultValue={['react', 'typescript']}
  renderValue={(selected, remove) => (
    <span>
      {selected.length} selected
      <button type="button" onClick={() => remove('react')}>
        Remove React
      </button>
    </span>
  )}
/>
```

## Accessibility

- Base UI renders the combobox input and the popup uses `role="listbox"` with
  `aria-multiselectable="true"`. Selected options expose `aria-selected="true"`.
- `ArrowDown` / `ArrowUp` browse options, `Enter` toggles the highlighted option, and `Escape` closes
  the popup and restores focus. `Tab` leaves the field.
- When `searchable` is true, typing filters options and `Space` inserts a space. Without search, the
  input is read-only and the chevron trigger opens the popup.
- Default chips include a labelled remove action, and Base UI handles Backspace/Delete removal while
  a chip is focused. `renderValue` replaces the chip content; its wrapper stops click propagation so
  custom controls do not toggle the popup.
- `required` and `name` are forwarded to the hidden form inputs managed by Base UI.
- The input exposes the selected count through `aria-description`.
- The select-all row is a `button` with `aria-pressed`, and the overflow counter is a `button` with
  an accessible name, so both are reachable without a pointer.
