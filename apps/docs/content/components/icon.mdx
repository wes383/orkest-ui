`Icon` wraps a Lucide icon component, applies a token-based size and stroke width, and handles the
accessible name. Icons inherit the current text color.

## Accessibility

Icons are decorative by default: they receive `aria-hidden="true"` and `focusable="false"`.

Provide a `label` only when the icon conveys meaning on its own:

```tsx
<Icon icon={Check} label="Completed" />
```

When the icon sits inside a control that already has an accessible name, leave the icon decorative:

```tsx
<button type="button" aria-label="Close dialog">
  <Icon icon={X} size="sm" />
</button>
```

Do not use an icon label to duplicate visible text in the same control. Use the icon as decoration
when the surrounding text already communicates the action.
