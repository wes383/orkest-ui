`Icon` wraps a Lucide icon component and applies token-based sizing, semantic color, and stroke
width. It preserves the accessible name rules that controls need, so icons compose cleanly with
`Button` and `IconButton`.

## Colors

`tone` uses semantic theme tokens, so icons change with the active theme. The default is `inherit`,
which keeps icons aligned with the foreground of the surrounding control.

export const semanticTonesCode = `import { Icon, Stack } from '@orkest/ui';
import { Check } from 'lucide-react';

export function Example() {
  return (
    <Stack direction="row" align="center" gap={4}>
      <Icon icon={Check} tone="default" />
      <Icon icon={Check} tone="muted" />
      <Icon icon={Check} tone="subtle" />
      <Icon icon={Check} tone="accent" />
      <Icon icon={Check} tone="success" />

## Stroke width

The default stroke width comes from `--ok-icon-stroke-width`. Override it per icon when a denser or
lighter treatment is needed.

export const strokeWidthsCode = `import { Icon, Stack } from '@orkest/ui';
import { Circle } from 'lucide-react';

export function Example() {

## Custom styles

Native SVG attributes, `className`, `style`, and refs are forwarded. Inline styles can use semantic
tokens when a one-off color is needed.

export const inlineStyleCode = `import { Icon } from '@orkest/ui';
import { Circle } from 'lucide-react';

export function Example() {
  return <Icon icon={Circle} size="xl" style={{ color: 'var(--ui-warning)' }} />;
}`;

<ComponentPreview title="Inline style" code={inlineStyleCode}>
  <Icon icon={Circle} size="xl" style={{ color: 'var(--ui-warning)' }} />
</ComponentPreview>

## Composition

`Button` and `IconButton` icon slots inherit sizing and color from the control. The same rules make
`Icon` ready for inputs and navigation items: use `size="inherit"` to match text, and leave the icon
decorative when the control already has a name.

export const insideButtonsCode = `import { Button, IconButton, Stack } from '@orkest/ui';
import { ArrowRight, Plus, Settings } from 'lucide-react';

export function Example() {
  return (
    <Stack direction="row" align="center" gap={2} wrap>
      <Button leftIcon={Plus}>New project</Button>
      <Button variant="secondary" rightIcon={ArrowRight}>
        Continue
      </Button>
      <IconButton icon={Settings} label="Settings" variant="outline" />
    </Stack>
  );
}`;

<ComponentPreview title="Inside buttons" code={insideButtonsCode}>

      {'Continue'}
    </Button>

</ComponentPreview>

## Accessibility

Icons are decorative by default: they receive `aria-hidden="true"` and `focusable="false"`.

Provide a `label` only when the icon conveys meaning on its own:

```tsx
<Icon icon={Check} label="Completed" />
```

When the icon sits inside a control that already has an accessible name, leave the icon decorative:

```tsx
<button type="button" aria-label="Close dialog">
  <Icon icon={X} size="sm" />
</button>
```

Do not use an icon label to duplicate visible text in the same control. Use the icon as decoration
when the surrounding text already communicates the action. Tone is not a substitute for meaning:
pair success or danger icons with text or another non-color cue.
