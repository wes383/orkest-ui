`Avatar` represents a person or entity with an image, initials, or an icon. It also provides presence
status and overlapping groups.

The image and fallback are built on Base UI Avatar, which owns loading status, cached image detection,
and fallback timing. Import the components from `@orkest/ui/client`.

## Live preview

export const avatarWithStatusCode = `import { Avatar, AvatarFallback, AvatarImage } from '@orkest/ui/client';

export function Example() {
  return (
    <Avatar size="lg" status="online">
      <AvatarImage src="/avatar.jpg" alt="Alex Morgan" />
      <AvatarFallback>{'AM'}</AvatarFallback>
    </Avatar>
  );
}`;

## Image and fallback

`AvatarFallback` is visible while the image loads, when no image is provided, and after a load
failure. By default the image stays mounted while loading or failed, but is hidden from assistive
technology until it loads, so the fallback remains the accessible content.

## Avatar group

`AvatarGroup` overlaps its children. `size` and `shape` cascade to avatars that do not set their own,
and `spacing` controls the overlap using a spacing token step.

export const overlappingAvatarsCode = `import { Avatar, AvatarFallback, AvatarGroup } from '@orkest/ui/client';

export function Example() {
  return (
    <AvatarGroup size="md" spacing={2}>

        <AvatarFallback>{'AM'}</AvatarFallback>
      </Avatar>
      <Avatar>
        <AvatarFallback>{'JL'}</AvatarFallback>

### Overflow

Set `max` to keep the first N avatars and replace the rest with a count. The group preserves child
order, so place the avatars that must stay visible first. `overflowLabel` customizes the accessible
text and defaults to `N more avatars`.

export const overflowCountCode = `import { Avatar, AvatarFallback, AvatarGroup } from '@orkest/ui/client';

export function Example() {
  return (
    <AvatarGroup max={3} size="md">

## Accessibility

- `AvatarImage` requires `alt`. Describe the person or entity, or pass an empty alt when the avatar
  is purely decorative.
- Use `label` on `Avatar` when the fallback is an icon or another visual without a text name. The
  visual content is hidden from assistive technology and the label becomes the accessible name.
- Status indicators always include visually hidden text. Default labels are Online, Away, Offline,
  and Busy; use `statusLabel` for product-specific wording.
- Do not communicate status with color alone. The status text is part of the accessible name, and
  surrounding UI should provide a visible equivalent when status is important.
- The group overflow indicator announces `N more avatars` by default. Customize it with
  `overflowLabel`.
- Avatars are not interactive. Wrap them in a [Button](/docs/components/button/) or use
  [Tag](/docs/components/tag/) for clickable chips.
