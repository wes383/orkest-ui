`Textarea` renders a native `<textarea>` inside the same token-styled field as
[Input](/docs/components/input/). It supports the shared control sizes, fixed and auto-resizing
heights, character counts, invalid, disabled, and read-only states, and fills the width of its
container.

`Textarea` is exported from `@orkest/ui/client`. Render it inside a Client Component.

## Height

Three modes cover the common cases:

- **Fixed** — set `rows` and `resize="none"`.
- **Auto resize** — set `autoResize` and the field grows with its content.
- **Min / max rows** — combine `autoResize` with `minRows` and `maxRows`; extra content scrolls.

<ComponentPreview
  title="Fixed, auto-resize, and bounded"
  code={`import { Box, Stack } from '@orkest/ui';
import { Textarea } from '@orkest/ui/client';

export function Example() {
  return (
    <Box style={{ width: '22rem' }}>
      <Stack gap={3}>
        <Textarea rows={4} resize="none" placeholder="Fixed height" aria-label="Fixed height" />
        <Textarea
          autoResize
          rows={2}
          defaultValue="Auto resize grows as this content becomes longer."
          aria-label="Auto resize"
        />
        <Textarea
          autoResize
          minRows={2}
          maxRows={5}
          defaultValue="Min and max rows keep the field between two and five visible lines."
          aria-label="Bounded rows"
        />
      </Stack>
    </Box>
  );
}`}
>
  <Box style={{ width: '22rem' }}>
    <Stack gap={3}>
      <Textarea rows={4} resize="none" placeholder="Fixed height" aria-label="Fixed height" />
      <Textarea
        autoResize
        rows={2}
        defaultValue="Auto resize grows as this content becomes longer."
        aria-label="Auto resize"
      />
      <Textarea
        autoResize
        minRows={2}
        maxRows={5}
        defaultValue="Min and max rows keep the field between two and five visible lines."
        aria-label="Bounded rows"
      />
    </Stack>
  </Box>
</ComponentPreview>

`resize` accepts `none`, `vertical`, `horizontal`, or `both`. It is ignored when `autoResize` is
enabled. Regardless of `rows`, `minRows`, or auto-resize, the field never shrinks below one line.

## Accessibility

- Provide an accessible name with `Label htmlFor` or `aria-label`. A placeholder is not a label.
- Connect help and error text with `aria-describedby`.
- `invalid` sets `aria-invalid`. Pair it with visible error text; do not rely on the border color
  alone.
- `disabled` and `readOnly` use the native attributes and remain distinguishable without color alone.
- Auto-resize and manual resize change presentation only; value and semantics are unchanged.
- The character count is supplementary. `maxLength` remains the native constraint.
- Focus is shown by darkening the field border; no separate focus ring is drawn. Invalid fields keep
  the danger border.
- Refs are forwarded to the native textarea element.
