`Box` is the neutral composition base for the library. It renders the element you choose, forwards
native props and refs, and adds only `box-sizing: border-box`.

## Overview

Use `Box` when a wrapper is needed but no layout or visual behavior should be imposed. Choose the
semantic element with `as` instead of adding ARIA roles to a `div`.

<Callout type="note" title="Box is not a layout system">
  Use [Stack](/docs/components/stack/) for one-dimensional layout. Box intentionally exposes no
  spacing, display, or color props.
</Callout>

`BoxProps<T>` is exported for wrapper components. The `as` prop drives the available native
attributes and the ref type.

## Accessibility

- `Box` adds no roles, labels, or keyboard behavior.
- Choose an element that matches the content, such as `section`, `nav`, `article`, or `ul`.
- Provide an accessible name when the chosen landmark needs one.
- Do not replace a native interactive element with a clickable Box.
