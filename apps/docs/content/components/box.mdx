`Box` is the general-purpose container. It renders the element you choose, forwards native props and
refs, and maps common design values to semantic tokens.

Box handles surfaces, spacing, borders, and dimensions. Use [Stack](/docs/components/stack/) for
one-dimensional layout and [Grid](/docs/components/grid/) for two-dimensional layout.

## Dimensions and padding

Numbers are treated as pixels; use any CSS length string for token-based or relative sizing.
`padding` accepts the shared spacing scale.

<ComponentPreview
  title="Constrained width"
  code={`import { Box, Text } from '@orkest/ui';

export function Example() {
  return (
    <Box width="100%" maxWidth="24rem" padding={4} background="surface-sunken" radius="xl">
      <Text size="sm" tone="muted">
        maxWidth keeps long content readable.
      </Text>
    </Box>
  );
}`}
>
  <Box width="100%" maxWidth="24rem" padding={4} background="surface-sunken" radius="xl">
    <Text size="sm" tone="muted">
      {'maxWidth keeps long content readable.'}
    </Text>
  </Box>
</ComponentPreview>

## Semantic colors

`background` and `color` map to theme-aware semantic variables, so the same Box works in light and
dark themes.

<ComponentPreview
  title="Surface and text tokens"
  code={`import { Box, Text } from '@orkest/ui';

export function Example() {
  return (
    <Box padding={4} background="accent-surface" color="accent" radius="xl">
      <Text size="sm" weight="medium">
        Accent surface
      </Text>
    </Box>
  );
}`}
>
  <Box padding={4} background="accent-surface" color="accent" radius="xl">
    <Text size="sm" weight="medium">
      {'Accent surface'}
    </Text>
  </Box>
</ComponentPreview>

drives the available native attributes and the ref type.

## Accessibility

- `Box` adds no roles, labels, or keyboard behavior.
- Choose an element that matches the content, such as `section`, `nav`, `article`, or `ul`.
- Provide an accessible name when the chosen landmark needs one.
- Do not use a clickable Box in place of a native button or link.
- Check color contrast when combining `background`, `color`, and theme variants.
