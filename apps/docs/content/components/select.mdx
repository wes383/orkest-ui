`Select` is a single-value combobox. Non-searchable use renders a select button; `searchable` renders
a filterable combobox input.

Import it from `@orkest/ui/client`.

## Live preview

export const basicSelectCode = `import { Select } from '@orkest/ui/client';

const fruits = [
  { value: 'apple', label: 'Apple' },
  { value: 'banana', label: 'Banana' },
  { value: 'cherry', label: 'Cherry' },
  { value: 'grape', label: 'Grape' },
  { value: 'mango', label: 'Mango' },
];

export function Example() {
  return <Select aria-label="Fruit" options={fruits} defaultValue="apple" clearable />;
}`;

## Searchable

Set `searchable` to turn the trigger into a text input. Typing filters option labels with a
case-insensitive match; clear the query to restore the full list. Pass `filterOption` to replace the
default matcher, or `onSearchChange` together with `loading` for async search.

Search mode is the same widget as [Combobox](/docs/components/combobox/), so filtering, groups,
loading, and keyboard behaviour are identical. The difference is the API: `Select` reports a cleared
value as `undefined` and always renders the standard option row, while `Combobox` uses `null` and
accepts `renderItem` / `loadingMessage`.

export const searchableSelectCode = `import { Select } from '@orkest/ui/client';

const languages = [
  { value: 'javascript', label: 'JavaScript' },
  { value: 'typescript', label: 'TypeScript' },
  { value: 'python', label: 'Python' },
  { value: 'go', label: 'Go' },
  { value: 'rust', label: 'Rust' },
  { value: 'swift', label: 'Swift' },
];

export function Example() {
  return (
    <Select
      aria-label="Language"
      options={languages}
      searchable
      searchPlaceholder="Search languages"
      placeholder="Choose a language"
    />
  );
}`;

<ComponentPreview title="Searchable select" code={searchableSelectCode}>
  <SearchableSelectExample />
</ComponentPreview>

For async search, return `true` from `filterOption` when the server already filtered the options:

```tsx
<Select
  searchable
  options={results}
  loading={loading}
  filterOption={() => true}
  onSearchChange={(query) => fetchOptions(query)}
/>
```

## Groups, descriptions, and icons

Options can be grouped and extended with `description`, `icon`, and `disabled`:

```ts
interface SelectOption {
  value: string;
  label: string;
  description?: ReactNode;
  icon?: LucideIcon;
  disabled?: boolean;
}

interface SelectOptionGroup {
  label: string;
  options: SelectOption[];
}
```

Groups render `role="group"` with the group label as the accessible name. Descriptions are visible
secondary text and are included in the option's accessible name. `icon` renders a decorative leading
icon; the trailing check is the selection indicator and is rendered automatically.

## States

`disabled` blocks interaction, `invalid` applies the danger border and `aria-invalid`, and
`clearable` adds a clear action while a value is selected.

export const disabledInvalidAndClearableCode = `import { Stack } from '@orkest/ui';
import { Select } from '@orkest/ui/client';

const statuses = [
  { value: 'active', label: 'Active' },
  { value: 'paused', label: 'Paused' },
  { value: 'archived', label: 'Archived' },
];

export function Example() {
  return (
    <Stack gap={3}>
      <Select aria-label="Disabled status" options={statuses} defaultValue="active" disabled />
      <Select
        aria-label="Invalid status"
        options={statuses}
        placeholder="Choose a status"
        invalid
      />
      <Select aria-label="Clearable status" options={statuses} defaultValue="paused" clearable />
    </Stack>
  );
}`;

shows `emptyMessage`.

## Accessibility

- The field exposes combobox and listbox semantics, including `role="option"`, `aria-expanded`,
  `aria-selected`, and `aria-disabled`.
- The popup inherits the surrounding theme.
- Outside pointer interactions, Escape, Tab, and selecting an option close the popup and restore
  focus.
- Disabled options are skipped by keyboard navigation.
- For single selection, `required` participates in native form validation, and `name` identifies the
  field.
- Associate a visible label with `id` and `htmlFor`, or use `aria-label` / `aria-labelledby`.

| Key                     | Behavior                                           |
| ----------------------- | -------------------------------------------------- |
| `Enter`                 | Opens the menu or selects the highlighted option   |
| `Space`                 | Opens the menu; inserts a space in searchable mode |
| `ArrowDown` / `ArrowUp` | Opens the menu or moves the highlight              |
| `Escape`                | Closes the menu and restores focus                 |
| `Tab`                   | Closes the menu and moves focus                    |
| Letter keys             | Typeahead; filters when searchable                 |
