title: Dropdown Menu
description: Menus that execute actions from a trigger.

`DropdownMenu` displays a list of commands after a trigger is pressed. Use it for actions such as
editing, duplicating, sharing, and deleting. It is not a Select: a menu executes commands, while a
Select chooses a form value.

The component is built on Base UI Menu and exported from `@orkest/ui/client`. Base UI owns
positioning, collision handling, dismissal, focus management, and keyboard navigation; Orkest UI owns
the visual design and public API.

Use `disabled` to make an item inert. Disabled items keep their place in the menu, cannot be
activated, and use a lower-emphasis foreground color.

## Anatomy

- `DropdownMenu` owns the open state and menu behavior.
- `DropdownMenuTrigger` opens the menu. It renders a secondary Button by default.
- `DropdownMenuPortal` moves the menu to the document body.
- `DropdownMenuContent` positions the surface, handles collisions, and scrolls long content.
- `DropdownMenuItem` executes an action and closes the menu.
- `DropdownMenuGroup` groups related items; `DropdownMenuLabel` names the group.
- `DropdownMenuSeparator` divides menu sections.
- `DropdownMenuShortcut` renders a visual keyboard hint at the end of an item.
- `DropdownMenuLinkItem` renders navigation as an anchor.
- `DropdownMenuCheckboxItem` toggles a setting without closing the menu.
- `DropdownMenuRadioGroup` and `DropdownMenuRadioItem` select one value without closing the menu.
- `DropdownMenuSub`, `DropdownMenuSubTrigger`, and `DropdownMenuSubContent` build nested menus.

Use `render` on `DropdownMenuTrigger` when the trigger should be an icon button, an avatar button, or
another custom element:

```tsx
<DropdownMenuTrigger render={<Button variant="ghost" aria-label="Project actions" />} />
```

## Positioning and sizing

`DropdownMenuContent` places the menu on the `bottom` side with `start` alignment by default. Override
`side`, `align`, `sideOffset`, and `alignOffset` when the trigger needs a different layout. Base UI
automatically flips the menu when it would overflow the viewport.

<ComponentPreview

  code={`import {

  return (

Use `minWidth` and `maxWidth` for predictable surfaces, or leave them unset to let the menu grow with
its content. `maxHeight` controls when the menu starts scrolling; by default it is limited by the
available viewport height.

## Item types

| Type | Component | Behavior |
| --- | --- | --- |
| Action | `DropdownMenuItem` | Executes an action and closes the menu |
| Link | `DropdownMenuLinkItem` | Renders an anchor and closes the menu after navigation |
| Destructive | `DropdownMenuItem variant="destructive"` | Uses the danger color for irreversible actions |
| Checkbox | `DropdownMenuCheckboxItem` | Toggles a setting and keeps the menu open |
| Radio | `DropdownMenuRadioItem` | Selects one value in a `DropdownMenuRadioGroup` |
| Submenu | `DropdownMenuSub` | Opens a nested menu |
| Shortcut | `DropdownMenuShortcut` | Displays a keyboard hint without changing the accessible name |

Mix icon and non-icon items with `inset` so labels stay aligned:

```tsx
<DropdownMenuItem leftIcon={Pencil}>Edit</DropdownMenuItem>
<DropdownMenuItem inset>Preferences</DropdownMenuItem>
```

## Accessibility

- `DropdownMenuContent` renders `role="menu"` and items render `role="menuitem"`,
  `menuitemcheckbox`, or `menuitemradio` as appropriate.
- `ArrowUp` and `ArrowDown` move through items, `Home` and `End` jump to the first and last items,
  and `Enter` or `Space` activates the highlighted item.
- `Escape` closes the menu and restores focus to the trigger. `Tab` moves focus out of the menu.
- Disabled items are exposed with `aria-disabled`, cannot be activated, and are skipped by arrow,
  Home, and End navigation.
- `DropdownMenuShortcut` is hidden from assistive technology so the accessible name stays concise.
- Destructive items keep their text label; color is not the only signal.
- `DropdownMenuLabel` is associated with its group automatically.
- The menu respects `prefers-reduced-motion` for its open and close animation.
