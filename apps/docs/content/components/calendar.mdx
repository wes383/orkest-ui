title: Calendar

`Calendar` is the grid on its own: it holds no input and no popover, so it can sit inline in a form, a
side panel, or a popover you already own. `DatePicker` builds on it, and a future range picker can
reuse it without changes.

Dates are plain `YYYY-MM-DD` strings. A calendar date has no time and no timezone, so it never shifts
to the previous day when the host timezone changes.

## Month and year switching

`captionLayout="select"` swaps the caption for month and year pickers, which is what someone booking
a date six months out actually wants.

<ComponentPreview
  title="Caption selects"
  code={`import { useState } from 'react';
import { Calendar } from '@orkest/ui/client';

export function Example() {
  const [value, setValue] = useState('2026-11-18');

  return (
    <Calendar
      value={value}
      onChange={setValue}
      defaultMonth="2026-11"
      captionLayout="select"
    />
  );
}`}
>
  <CalendarCaptionSelectExample />
</ComponentPreview>

The header arrows stay available in both layouts. A disabled bound is reflected on the arrow, so the
reader can see there is nothing earlier or later to reach.

Both pickers are listbox comboboxes rendered by the component rather than native `select` elements,
so the panel follows the same surface, radius, and shadow tokens as the rest of the library, and the
focused trigger does not pick up the browser's blue focus box.

## Range limits and blocked dates

`minDate` and `maxDate` are inclusive. `disabledDates` takes either a list of `YYYY-MM-DD` strings or a
predicate, so a rule like "no weekends" stays a one-liner.

<ComponentPreview
  title="Bounded range"
  code={`import { useState } from 'react';
import { Calendar } from '@orkest/ui/client';

export function Example() {
  const [value, setValue] = useState('2026-11-16');

  return (
    <Calendar
      value={value}
      onChange={setValue}
      defaultMonth="2026-11"
      minDate="2026-11-10"
      maxDate="2026-11-24"
      disabledDates={['2026-11-13', '2026-11-20']}
    />
  );
}`}
>
  <CalendarRangeExample />
</ComponentPreview>

Blocked days stay focusable and announce `aria-disabled`, so keyboard users can move past them
without losing their place. Selecting one does nothing.

`size` scales the cell, the text, and the spacing together. `sm` fits a filter bar; `lg` is for a
standalone date page. `md` is the default.

## Composition

`Calendar` renders `CalendarHeader` and `CalendarGrid` by default. Pass children to replace that
composition; the parts read their state from the surrounding calendar, so you can reorder them or drop
the header entirely.

```tsx
import { Calendar, CalendarGrid, CalendarHeader } from '@orkest/ui/client';

export function CompactCalendar() {
  return (
    <Calendar defaultMonth="2026-11">
      <CalendarHeader />
      <CalendarGrid showWeekdays={false} />
    </Calendar>
  );
}
```

`CalendarDay` is exported for cases that need a custom grid, and throws when rendered outside a
`Calendar` because it has no state of its own.

## Formats and locale

- `locale` drives month names, weekday names, and the accessible label of every day. It defaults to
  `en-US`.
- `weekStartsOn` accepts `0`–`6` from Sunday. When omitted it is derived from `locale`, so `zh-CN`
  starts on Monday without extra configuration.
- `formatISODate`, `parseISODate`, `addDays`, `addMonths`, `weekdayOf`, and `todayDate` are exported
  from `@orkest/ui/client` so callers can do date math without pulling in another library.

## Accessibility

- The grid is a single tab stop. Arrow keys move by day, `Home` and `End` jump to the ends of the
  week, `PageUp` and `PageDown` change month, and holding `Shift` changes year.
- Every day exposes its full date as its accessible name, plus `aria-selected` and
  `aria-current="date"` for today, so the reader never has to infer the month from position.
- The header arrows are icon buttons with names that follow the locale labels.
- The month and year pickers are comboboxes over a listbox: arrow keys move the highlight, `Enter`
  commits, and `Escape` closes the panel without changing the month.
- Focus follows the navigated date, including when a key press lands in another month.
