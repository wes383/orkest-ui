`Tabs` switches between related panels without navigating away. Use underline tabs for regular
content navigation, pills for compact view switching, and enclosed tabs for settings or segmented
panels.

The component is built on Base UI Tabs and exported from `@orkest/ui/client`.

## Basic usage

export const underlineTabsCode = `import { Stack, Text } from '@orkest/ui';
import { Tabs, TabsContent, TabsIndicator, TabsList, TabsTrigger } from '@orkest/ui/client';

export function Example() {
  return (
    <Tabs defaultValue="overview">
      <TabsList>
        <TabsTrigger value="overview">Overview</TabsTrigger>
        <TabsTrigger value="activity">Activity</TabsTrigger>
        <TabsTrigger value="settings">Settings</TabsTrigger>
        <TabsIndicator />
      </TabsList>
      <TabsContent value="overview">
        <Text size="sm" tone="muted">
          A summary of the project, recent changes, and open work.
        </Text>
      </TabsContent>
      <TabsContent value="activity">
        <Text size="sm" tone="muted">
          Commits, reviews, and comments from the last seven days.
        </Text>
      </TabsContent>
      <TabsContent value="settings">
        <Text size="sm" tone="muted">
          Visibility, members, and notification preferences.
        </Text>
      </TabsContent>
    </Tabs>
  );
}`;

## Anatomy

- `Tabs` owns the selected value and connects tabs to their panels.
- `TabsList` is the tab strip. It also controls keyboard behavior through `activationMode` and
  `loop`.
- `TabsTrigger` is one tab. The `value` prop must match the corresponding `TabsContent`.
- `TabsContent` is the panel for a value. Only the active panel is rendered by default.
- `TabsIndicator` is an optional moving highlight. Place it inside `TabsList`, after the triggers.

String values keep state stable when tabs are added, removed, or reordered. Avoid array indexes.

## Variants

`underline` is the default and fits regular content navigation.

`pills` uses a filled active tab and works well for compact view switching.

export const pillsCode = `import { Tabs, TabsContent, TabsIndicator, TabsList, TabsTrigger } from '@orkest/ui/client';

export function Example() {
  return (
    <Tabs defaultValue="day">

        <TabsTrigger value="week">Week</TabsTrigger>
        <TabsTrigger value="month">Month</TabsTrigger>

## Vertical tabs

Set `orientation="vertical"` on `Tabs`. The root lays the list beside the active panel by default,
and the arrow keys switch to ArrowUp and ArrowDown.

## Activation mode

`activationMode` controls what happens when an arrow key moves focus.

- `automatic` (default) activates the focused tab immediately. Use it when panels are already
  available.
- `manual` moves focus only and waits for Enter or Space. Use it when switching triggers expensive
  work such as a network request.

export const manualActivationCode = `import { Stack, Text } from '@orkest/ui';
import { Tabs, TabsContent, TabsIndicator, TabsList, TabsTrigger } from '@orkest/ui/client';

export function Example() {
  return (
    <Tabs defaultValue="details">
      <TabsList activationMode="manual">
        <TabsTrigger value="details">Details</TabsTrigger>
        <TabsTrigger value="members">Members</TabsTrigger>
        <TabsTrigger value="history">History</TabsTrigger>
        <TabsIndicator />
      </TabsList>
      <TabsContent value="details">
        <Text size="sm" tone="muted">
          Arrow keys move focus. Press Enter or Space to load a panel.
        </Text>
      </TabsContent>
      <TabsContent value="members">
        <Text size="sm" tone="muted">
          Members load only after you confirm the selection.
        </Text>
      </TabsContent>
      <TabsContent value="history">
        <Text size="sm" tone="muted">
          History keeps the current panel until you activate it.
        </Text>
      </TabsContent>
    </Tabs>
  );
}`;

## Controlled state

export const controlledTabsCode = `import { useState } from 'react';

export function Example() {

          <TabsIndicator />

      </Tabs>
      <Text size="sm" tone="muted">
        Active tab: {value}

    </Stack>
  );
}`;

## Disabled tabs

Disable a single tab with `TabsTrigger disabled`. Disable the whole list with `Tabs disabled`; the
active panel stays visible but the list no longer accepts pointer or keyboard interaction.

Disabled tabs are skipped by arrow-key navigation, Home, and End.

export const disabledStatesCode = `import { useState } from 'react';
import { Stack } from '@orkest/ui';
import { Switch, Tabs, TabsContent, TabsIndicator, TabsList, TabsTrigger } from '@orkest/ui/client';

export function Example() {
  const [disabled, setDisabled] = useState(false);

  return (
    <Stack gap={3}>
      <Switch label="Disable the whole tab list" checked={disabled} onCheckedChange={setDisabled} />
      <Tabs defaultValue="general" disabled={disabled}>
        <TabsList>
          <TabsTrigger value="general">General</TabsTrigger>
          <TabsTrigger value="billing" disabled>
            Billing
          </TabsTrigger>
          <TabsTrigger value="advanced">Advanced</TabsTrigger>
          <TabsIndicator />
        </TabsList>
        <TabsContent value="general">General settings.</TabsContent>
        <TabsContent value="billing">Billing settings.</TabsContent>
        <TabsContent value="advanced">Advanced settings.</TabsContent>
      </Tabs>
    </Stack>
  );
}`;

## Keyboard interaction

| Key                    | Behavior                                |
| ---------------------- | --------------------------------------- |
| ArrowLeft / ArrowRight | Move focus between horizontal tabs      |
| ArrowUp / ArrowDown    | Move focus between vertical tabs        |
| Home / End             | Move to the first or last enabled tab   |
| Enter / Space          | Activate the focused tab in manual mode |
| Tab                    | Move into or out of the tab list        |

Focus wraps at the ends by default. Set `loop={false}` on `TabsList` to stop at the last tab.
Disabled tabs are skipped.

## Accessibility

- `TabsList` renders `role="tablist"` and exposes the orientation to assistive technology.
- Each `TabsTrigger` renders `role="tab"` with `aria-selected`, and is linked to its panel through
  `aria-controls`.
- Each `TabsContent` renders `role="tabpanel"` and is named by its tab.
- Only the active panel is focusable and exposed; inactive panels are inert.
- Disabled tabs use `aria-disabled` and cannot be activated.
- Keyboard focus is always visible.
- The indicator is decorative and does not affect the accessible name.
- Motion respects `prefers-reduced-motion`.
