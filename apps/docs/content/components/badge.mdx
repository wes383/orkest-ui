`Badge` labels status, metadata, counts, or removable tags. It is decorative by default and renders a
`span`. With `interactive`, it renders a native button and supports keyboard and focus behavior.

## Icons and dots

Icons are decorative. A leading dot inherits the variant accent color. With no content, `dot`
renders a standalone status dot; give it an `aria-label` when the status is meaningful.

<ComponentPreview

## Count

`count` takes precedence over children. Values above `maxCount` render as `maxCount+`.

<ComponentPreview
  title="Counts"
  code={`import { Badge, Stack } from '@orkest/ui';

  return (
    <Stack direction="row" gap={2} align="center" wrap>
      <Badge count={8} variant="destructive" shape="pill" />
      <Badge count={120} maxCount={99} variant="info" shape="pill" />
    </Stack>
  );
}`}

## Removable

<ComponentPreview
  title="Removable tags"
  code={`import { useState } from 'react';
import { Badge, Stack } from '@orkest/ui';

export function Example() {
  const [tags, setTags] = useState(['Design', 'Engineering']);

  return (
    <Stack direction="row" gap={2} wrap>
      {tags.map((tag) => (
        <Badge
          key={tag}
          removable
          onRemove={() => setTags((current) => current.filter((item) => item !== tag))}
        >
          {tag}
        </Badge>
      ))}
    </Stack>
  );
}`}
>

## Accessibility

- Non-interactive badges render a `span`. Do not attach click handlers; use `interactive` for
  clickable badges.
- Interactive badges render a native `<button type="button">` with keyboard activation and a
  focus-visible ring.
- Removable badges stay non-interactive as a whole so the remove action can be a native button.
  `interactive` is ignored when `removable` is set.
- The remove action has an accessible name from `removeLabel`.
- A standalone dot needs an `aria-label` when its status is meaningful.
- Icons are decorative and hidden from assistive technology.
- Do not communicate status with color alone. Pair variants and custom colors with text or a dot
  label.
- Check contrast when using custom colors.
