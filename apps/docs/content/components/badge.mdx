`Badge` labels status, metadata, and counts. It is decorative by default and renders a `span`. For
removable or clickable chips, use [Tag](/docs/components/tag/).

## Icons and dots

Icons are decorative. A leading dot inherits the variant accent color. With no content, `dot`
renders a standalone status dot; give it an `aria-label` when the status is meaningful.

<ComponentPreview
  title="Icons and status dots"
  code={`import { Badge, Stack } from '@orkest/ui';
import { Check, Circle } from 'lucide-react';

export function Example() {
  return (
    <Stack direction="row" gap={2} align="center" wrap>
      <Badge variant="info" leftIcon={Circle}>
        Info
      </Badge>
      <Badge variant="success" rightIcon={Check}>
        Done
      </Badge>
      <Badge variant="success" dot>
        Online
      </Badge>
      <Badge variant="success" dot aria-label="Online" />
    </Stack>
  );
}`}
>
  <Stack direction="row" gap={2} align="center" wrap>
    <Badge variant="info" leftIcon={Circle}>
      {'Info'}
    </Badge>
    <Badge variant="success" rightIcon={Check}>
      {'Done'}
    </Badge>
    <Badge variant="success" dot>
      {'Online'}
    </Badge>
    <Badge variant="success" dot aria-label="Online" />
  </Stack>
</ComponentPreview>

## Count

`count` takes precedence over children. Values above `maxCount` render as `maxCount+`.

<ComponentPreview
  title="Counts"
  code={`import { Badge, Stack } from '@orkest/ui';

export function Example() {
  return (
    <Stack direction="row" gap={2} align="center" wrap>
      <Badge count={8} variant="destructive" shape="pill" />
      <Badge count={120} maxCount={99} variant="info" shape="pill" />
    </Stack>
  );
}`}
>
  <Stack direction="row" gap={2} align="center" wrap>
    <Badge count={8} variant="destructive" shape="pill" />
    <Badge count={120} maxCount={99} variant="info" shape="pill" />
  </Stack>
</ComponentPreview>

## Custom color

`color` creates a tinted badge while keeping the theme surface underneath. Check text contrast when
using light or low-contrast colors.

## Accessibility

- Badges render a `span` and are not interactive. Use [Tag](/docs/components/tag/) for removable or
  clickable chips.
- A standalone dot needs an `aria-label` when its status is meaningful.
- Icons are decorative and hidden from assistive technology.
- Do not communicate status with color alone. Pair variants and custom colors with text or a dot
  label.
- Check contrast when using custom colors.
