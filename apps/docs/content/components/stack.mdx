`Stack` arranges items in a row or column and applies a spacing token as the gap. It is the default
one-dimensional layout primitive for vertical rhythm and simple horizontal groups. Use
[Grid](/docs/components/grid/) when items need two-dimensional placement.

## Accessibility

`Stack` does not add ARIA roles or keyboard behavior. It only changes visual layout.

- Reading order remains DOM order. Avoid visual reordering that contradicts the source order.
- Use `as` to render semantic elements such as `ul`, `nav`, or `section` when appropriate.
- Direction and alignment are visual concerns; they should not change the meaning of the content.
