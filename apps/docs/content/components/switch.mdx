`Switch` is a Base UI switch with token styling. It supports controlled and uncontrolled state,
labels, sizes, form submission, and Space-key toggling.

Import it from `@orkest/ui/client`.

## Live preview

export const controlledSwitchCode = `import { useState } from 'react';
import { Switch } from '@orkest/ui/client';

export function Example() {
  const [enabled, setEnabled] = useState(true);

  return (
    <Switch
      label="Email notifications"
      checked={enabled}
      onCheckedChange={setEnabled}
    />
  );
}`;

## Accessibility

- Renders a Base UI switch with `role="switch"` and a hidden native input for form submission.
- Space toggles the switch while focused; Base UI handles the keyboard interaction.
- The optional `label` is an implicit label. When omitting it, provide `aria-label`,
  `aria-labelledby`, or use `FieldLabel`.
- Focus is shown on the track with `:focus-visible`.
- Inside an ancestor with `dir="rtl"`, the switch mirrors automatically.
- The thumb transition is disabled when `prefers-reduced-motion: reduce` is active.
