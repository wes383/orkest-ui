`Switch` is a native checkbox rendered as a switch. It supports controlled and uncontrolled state,
labels, sizes, form submission, and Space-key toggling.

Import it from `@orkest/ui/client`.

## Live preview

<ComponentPreview
  title="Controlled switch"
  code={`import { useState } from 'react';
import { Switch } from '@orkest/ui/client';

export function Example() {
  const [enabled, setEnabled] = useState(true);

  return (
    <Switch
      label="Email notifications"
      checked={enabled}
      onChange={(event) => setEnabled(event.currentTarget.checked)}
    />
  );
}`}
>
  <SwitchExample />
</ComponentPreview>

## Accessibility

- Renders a native `<input type="checkbox">` with `role="switch"` and an explicit `aria-checked`
  state.
- Space toggles the switch while focused; no custom keyboard handling is required.
- The optional `label` is an implicit label. When omitting it, provide `aria-label` or connect an
  external label with `id` and `htmlFor`.
- Focus is shown on the track with `:focus-visible`.
- The thumb transition is disabled when `prefers-reduced-motion: reduce` is active.
