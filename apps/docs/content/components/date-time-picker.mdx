`DateTimePicker` pairs a [Calendar](/docs/components/calendar/) with the segmented field from
[TimePicker](/docs/components/time-picker/). The value is a `YYYY-MM-DDTHH:mm` string — wall-clock
time with no offset — so it never shifts when the host timezone changes.

## Live preview

export const basicDateAndTimePickerCode = `import { useState } from 'react';
import { Stack, Text } from '@orkest/ui';
import { DateTimePicker } from '@orkest/ui/client';

export function Example() {
  const [value, setValue] = useState<string | null>('2026-11-18T09:30');

  return (
    <Stack gap={2} align="start" style={{ width: '100%', maxWidth: '16rem' }}>
      <DateTimePicker value={value} onChange={setValue} />
      <Text size="sm" tone="muted">
        Value: {value ?? 'none'}
      </Text>
    </Stack>
  );
}`;

The panel stays open while you work: pick the day, then step or type the time, and press `Done` when
the value is right. The two halves are independent, so the order does not matter — a time typed before
the day is remembered and used as soon as a date is picked.

## 12-hour clock and minute step

`timeFormat` switches the clock face to a 12-hour one with an `AM/PM` segment, and `minuteStep` sets
both the arrow-key step and the interval the panel offers.

export const example12HourClockInQuarterHoursCode = `import { useState } from 'react';
import { DateTimePicker } from '@orkest/ui/client';

export function Example() {
  const [value, setValue] = useState<string | null>('2026-11-18T14:45');

  return (
    <DateTimePicker
      value={value}
      onChange={setValue}
      timeFormat="12h"
      minuteStep={15}
      style={{ width: '100%', maxWidth: '16rem' }}
    />
  );
}`;

## Column menu for the time

`timeMode="menu"` swaps the segmented field for the scrollable hour, minute, and second columns
that [TimePicker](/docs/components/time-picker/) opens in its own panel. They sit to the right of
the grid, so the panel stays about as tall as the calendar, and every click commits at once. The
columns follow `timeFormat`, `minuteStep`, and `showSeconds`, so the stored value keeps the same
shape.

export const timePickedFromColumnsCode = `import { useState } from 'react';
import { DateTimePicker } from '@orkest/ui/client';

export function Example() {
  const [value, setValue] = useState<string | null>('2026-11-18T09:30');

  return (
    <DateTimePicker
      value={value}
      onChange={setValue}
      timeMode="menu"
      style={{ width: '100%', maxWidth: '16rem' }}
    />
  );
}`;

## Inside a Field

The trigger reads the surrounding [Field](/docs/components/field/) context, and `minDate`, `maxDate`,
and `disabledDates` bound the calendar the same way they do for `DatePicker`.

export const withALabelAndDescriptionCode = `import { useState } from 'react';
import { DateTimePicker, Field, FieldDescription, FieldLabel } from '@orkest/ui/client';

export function Example() {
  const [value, setValue] = useState<string | null>(null);

  return (
    <Field style={{ width: '100%', maxWidth: '16rem' }}>
      <FieldLabel>Publish at</FieldLabel>
      <DateTimePicker value={value} onChange={setValue} />
      <FieldDescription>Stored as local wall-clock time.</FieldDescription>
    </Field>
  );
}`;

## Accessibility

- The trigger is a button with `aria-haspopup="dialog"` and `aria-expanded`. `Escape` closes the panel
  and returns focus to it.
- Inside the panel, the grid is a single tab stop with full arrow-key navigation, described in the
  [Calendar documentation](/docs/components/calendar/#accessibility).
- The time half is the same segmented field as `TimePicker` by default: one `spinbutton` per unit,
  each with its own label, range, and value, and the selected digits are the focus indicator. With
  `timeMode="menu"`, each column is a `listbox` driven by the arrow keys, `Home`, and `End`.
- `Now` and `Done` are ordinary buttons in the tab order, after the grid and the time field.
