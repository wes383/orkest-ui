`Text` renders a span by default and provides the token-driven typography options shared by the rest
of the [typography family](/docs/components/typography/). It accepts any element through `as`, so it
can also render paragraphs, headings, and list content.

## Sizes and weights

`Text` supports the full type scale from `2xs` to `5xl`, plus `inherit` for nested inline content.
Weights are `regular`, `medium`, `semibold`, and `bold`.

## Overflow

`truncate` is single-line; `lineClamp` is multi-line and takes precedence when both are set. The full
text remains available to assistive technology.

export const truncationCode = `<Box style={{ width: '22rem' }}>
  <Stack gap={2}>
    <Text as="p" truncate>
      Single-line truncation keeps long copy from wrapping onto a second line.
    </Text>
    <Text as="p" lineClamp={2}>
      Multi-line clamping stops after two lines and hides the remainder, which is useful for
      previews and summaries.
    </Text>
  </Stack>
</Box>`;

## Accessibility

- `Text` defaults to a span. Use `as` to render the correct semantic element.
- Do not skip heading levels. A visual size does not determine the heading level; use
  [Heading](/docs/components/typography/) for headings.
- Truncation and line clamping are visual; the full text remains available to assistive technology.
- Tone is not a substitute for context. Pair success or danger text with a clear label or icon.
- Inherited native attributes such as `id`, `title`, and event handlers are forwarded.
