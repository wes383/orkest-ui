`Text` renders a span by default and provides a small, token-driven set of typographic options. It
accepts any element through `as`, so it can also render paragraphs, headings, and list content.

## Accessibility

- `Text` defaults to a span. Use `as` to render the correct semantic element.
- Do not skip heading levels. A visual size does not determine the heading level.
- Truncation is visual; the full text remains in the DOM for assistive technology.
- Tone is not a substitute for context. Pair success or danger text with a clear label or icon.
- Inherited native attributes such as `id`, `title`, and event handlers are forwarded.
