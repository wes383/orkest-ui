`@orkest/ui` is published on npm. Install it with the package manager your application already uses.

## Requirements

- React 18.2 or React 19, with a matching React DOM version.
- TypeScript is recommended for the public prop types.

## Install the package

<InstallCommand />

## Load the styles

Import the compiled stylesheet once in the application root:

```tsx
import '@orkest/ui/style.css';
```

The stylesheet contains the design tokens, light and dark theme mappings, and component styles. It
does not load font files or override host application typography.

## Entry points

- `@orkest/ui` — server-safe primitives, typography, `Badge`, `Tag`, `Button`, and `IconButton`.
- `@orkest/ui/client` — every interactive component: form controls, `Select`, `MultiSelect`, `Tabs`,
  `Dialog`, `AlertDialog`, `DropdownMenu`, `Popover`, `Tooltip`, `Toast`, `Alert`, `Avatar`, and the
  `Field` parts. They use client-side state and must render inside a Client Component.
- `@orkest/ui/style.css` — the compiled stylesheet.

The component reference lists every export.

## Working inside this repository

The documentation site consumes the built `dist` output, so build the library before starting it:

```bash
pnpm --filter @orkest/ui build
```

The `apps/docs` scripts run this step automatically before `dev`, `build`, and `typecheck`.

## Peer dependencies

React and React DOM are peer dependencies. `lucide-react` is a regular dependency because `Icon`
uses it for its icon primitives. `@base-ui/react` is a regular dependency that supplies overlay and
popup behavior for interactive components.
