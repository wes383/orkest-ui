Add `Command` and refine the library's visual details.

- New `Command` palette with inline and dialog compositions, filtering, keyboard navigation, and a
  `Command.Footer` hint bar.
- Buttons accept `data-focus-ring="none"` to suppress the ring when focus is restored
  programmatically.
- Component titles use the medium weight, calendar caption menus animate their chevron, scrollbars
  share one inset, arrow-free skin, and dialog focus rings are no longer clipped while scrolling.
