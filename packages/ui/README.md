# @orkest/ui

Neutral-first React component library with semantic design tokens, accessible primitives, and light
and dark themes.

Documentation: [ui.wesluma.com/docs](https://ui.wesluma.com/docs/)

## Status

Published on npm. The public API may still change before `1.0.0`.

## Install

```bash
pnpm add @orkest/ui
```

React 18.2 or React 19 is required.

Import `@orkest/ui/style.css` once in your application. Client-side components are exported from
`@orkest/ui/client` and must render inside a Client Component (a module with `'use client'`).
